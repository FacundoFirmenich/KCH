# KwanCode Dynamic Bayesian Metaarchitecture v0.4.0

## Decisive change

The controller is now an active epistemic policy. Abstention is the final
fail-closed state, not the first response to uncertainty.

prior memory
-> pre-decision probes
-> preliminary local authority
-> typed doubt
-> ASK / PROBE / VERIFY_FULL / DEFER by expected information value
-> final local authority
-> route freeze
-> CAS/QAS support gate
-> actuation or full fallback
-> adjudication
-> Z_post
-> future OBL

Doubt is typed as conflicting local authorities, insufficient response,
support or fidelity, unresolved harm, lower-tail risk, out-of-distribution
evidence, stale information or failure to beat baseline.

An acquisition is selected only if explicit answer scenarios imply positive
expected sample information value after direct, latency and risk cost.

CAS/QAS records stepwise identity, decision identity, first divergence,
support fractions, retained selected-operator energy and total-variation
distance. Localized execution is authorized only when every frozen gate passes;
otherwise full execution is required or the system abstains.

The recovered QAS material supports zero divergences on recorded paired
QAS/full contrasts from an executed Qwen campaign. This is not a universal
guarantee. The author-reported 0.0837 and median 0.0567 remain pending unit and
row-level reconciliation before external use.
