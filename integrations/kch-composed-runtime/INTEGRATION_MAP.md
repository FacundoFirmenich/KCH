# KCH composition: implementation and remaining boundaries

This package is additive to KCH. It preserves KCH as the owning architecture rather than reducing it to a generic permission wrapper. KCH SuperMCP, Jarvis/Telegram, Ava-derived remote surfaces, KwanCode, CSI, KwanDocs, KwanBlocks, CONSTRUCT, Studio/Workbench, scheduler, TokenMaster and the rest of the existing capabilities retain their own implementation and activation state. This package neither replaces them nor claims to have connected every one of them.

The two selectable host compositions are **KCH + QwenPaw** and **KCH + OpenClaw**. The DeepSeek native plugin contributes a separate execution-boundary integration. A provider API transport is a fourth, distinct concern. Sharing a memory database does not merge authority, sessions or host-native execution state.

## Required preservation contracts

- **Full own capability set:** advertise only the tools actually connected, while preserving the separate installed KCH inventory. Missing connection is not evidence that the original capability does not exist.
- **One external-effect owner:** platform choice, subagent roles and model routing never create a second sender or scheduler owner for the same task. External delivery uncertainty requires reconciliation rather than blind replay.
- **Authority survives composition:** prompts, retrieved documents, folded summaries, sensor scores and agent roles cannot create permission. The actual executor must consult the appropriate KCH/native host gate.
- **Continuity is explicit:** a task's own identity and obligations remain distinct from an OpenClaw/QwenPaw/Codex-native session. Handover requires source receipt, destination acceptance and state reconciliation.
- **Originals remain recoverable:** changing active context or an index never deletes the source evidence. Derived memory cannot rewrite a completed scientific result or closed CSI state; corrections are successors.
- **Capabilities are not activation:** configuration prepared, discovered tool, executed local test, real-host probe and live workflow completion are separate evidence states.

## Primary mechanisms and applicability

ReMe's [official repository](https://github.com/agentscope-ai/ReMe) and [DSH integration](https://reme.agentscope.io/en/integrations/dsh) support file-native derived memory and lifecycle integration. Its current `auto_memory` filters tool results and base64 data, while its DSH capture collects user/assistant text. That filtering is useful against recapture contamination but precludes treating the result as a complete transcript archive.

[MiMo Code](https://github.com/XiaomiMiMo/MiMo-Code) contributes checkpoint reconstruction, recent-tail retention and paginated history recovery. Source code carries MIT licensing and a separate use-restrictions document; this package's mechanisms are original integration code and do not imply all MiMo source has been incorporated. [Kimi Code](https://github.com/MoonshotAI/kimi-code) separates compacted context from each agent's append-only event log. [Z.ai Synapse](https://github.com/zai-org/Synapse) has transactional shared/private archive chains and permissioned memory, while explicitly describing itself as early-stage.

[OpenViking](https://github.com/volcengine/OpenViking) is a relevant additional Chinese system from Volcengine: hierarchical resource URIs and L0/L1/L2 retrieval remain an extension path, not an implemented semantic layer in this package. [AgentFold](https://arxiv.org/abs/2510.24699) is Alibaba's multi-scale folding research; its reported performance includes supervised fine-tuning. [DeepSeek Engram](https://github.com/deepseek-ai/Engram) operates inside a trained model and is not a harness-memory plugin; its illustrative demo is not incorporated as a functioning KCH component.

The earlier research inventory and private experimental evidence are delivered separately from this public proposal. Current executable boundaries, upstream pins and acceptance receipts are documented in `VERIFICATION.md`, `docs/` and `tests/host_acceptance/`; inspected mechanisms, author-reported results and locally executed acceptance are distinct evidence categories.
