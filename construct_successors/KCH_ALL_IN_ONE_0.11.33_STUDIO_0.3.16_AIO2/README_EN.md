# KCH All-in-One 0.11.33 + Studio 0.3.16 — AIO2

This versioned successor preserves the stable R21 and R33 native lineages, fixes marketplace-relative host projection, adds a field-level Contractual Rigor Fader, and exposes one non-duplicated Codex projection, KCH Studio 0.3.16, the complete Super-MCP, an offline wheelhouse, and transactional adapters for Codex and Cline in Visual Studio Code.

It does not inspect, incorporate, or modify any R34 branch. R21 and R33 are not removed; operational replacement is only eligible after an isolated install and a fresh-session validation.

Local deployment follows `CLOUD_FIRST_LOCAL_MINIMAL`: only the required runtime and host projections are installed locally, while the sealed ZIP is the custody object.
