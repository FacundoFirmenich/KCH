# KCH All-in-One 0.11.33-aio.3

Sucesor incremental y reproducible de AIO2 que convierte el cierre sustantivo en un contrato CSI común y lo proyecta a Codex, ChatGPT y Cline según las capacidades reales de cada host.

AIO3 se construye únicamente sobre el asset universal público de `v0.11.33-aio.2` cuyo SHA-256 fijado es `be9ce17553ac534fbe66c5764abcc9e30b630ff5a04f16a73570b7264fdae78b`. No reescribe AIO2 ni los linajes R21/R33. El build completo se ejecuta en GitHub Actions para mantener la custodia cloud-first y minimizar almacenamiento local.

La promoción automática permanece deshabilitada. Un source pass no equivale a instalación viva ni a activación observada en ningún host.
