# Adaptive intervention, safety, and counterfactual stopping

The parent gate 011 produced a minimum static two-intervention design. Gate 012 treats that design as a contingent plan: the first result can make the second intervention unnecessary, required, unsafe, or unauthorized.

Across 25,000 simulated episodes, the observed error rate was 1.208%. Mean cost was 21.1301 versus 24.2 for the parent's fixed 11+11 burden, and mean declared risk was 0.4372 versus 0.99. These operational comparisons are not inferentially identical: the adaptive gate has a separate anytime familywise error bound <=5%, whereas the parent fixed-n classifier was reported empirically.

The counterfactual ledger records interventions that the parent plan would have executed but the child cancelled. It is provenance, not evidence.
