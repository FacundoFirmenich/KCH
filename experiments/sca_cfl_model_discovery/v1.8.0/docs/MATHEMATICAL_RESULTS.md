# Mathematical results — Model-class discovery v1.8

Inherited class: finite (mathcal M_0). A fixed predictive alternative (Q) defines
[
E_t^{outer}=Q(Y_{1:t}|A_{1:t})/max_{minmathcal M_0}P_m(Y_{1:t}|A_{1:t}).
]
Under any true (m^*inmathcal M_0), this is pointwise dominated by the likelihood-ratio martingale (Q/P_{m^*}), so threshold crossing is anytime-valid.

Discovery and confirmation are separated. Structure is selected only from prefix (D), frozen, then reset and evaluated on future stream (V). Conditional on (D), the selected depth is fixed, so the same composite-null domination argument applies.

The generator is a sieve-style variable-memory grammar whose allowed depth grows with discovery sample size. It is not claimed to be a full infinite-dimensional BNP posterior.

A probabilistic/statistical candidate may become model-class eligible while remaining `PROTOFORM_REALVIRTUAL_+0`. Statistical evidence cannot promote it to CFL `FORM_1`.
