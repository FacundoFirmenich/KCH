# SCA/CFL Minimal Intervention Design v2.0.0

Gate `MINIMAL_INTERVENTION_DESIGN_AND_IDENTIFIABILITY_FRONTIER_011`.

Transporta la equivalence class real de v1.9 a un problema de test-cover/hitting-set: 117 programas sintácticos colapsan a 5 clases predictivas globales. El mínimo exacto para identificar la clase semántica usa `do(x=0,z=1)` y `do(x=1,z=0)` con coste 2.2. Aun con ambas quedan 1,870 pares sintácticos prediction-equivalent bajo todo el dominio binario x,z. Un counterexample separado congela greedy=6.7 frente a óptimo exacto=5.2.

Todo candidato continúa en CFL `PROTOFORM_REALVIRTUAL_+0`.
