# From observational equivalence to a minimum experimental program

Gate 010 identified one pairwise distinguishing intervention. Gate 011 lifts the problem to an entire equivalence class. The target is a minimum-cost set of authorized interventions that separates every separable hypothesis pair, while returning non-separable pairs explicitly as an identifiability frontier.

The v1.9 parent is revealing: two off-support interventions identify the five predictive semantic classes, but no intervention program over x,z can identify raw syntax inside a global predictive equivalence class. The system therefore refuses to turn semantic identification into ontological uniqueness.
