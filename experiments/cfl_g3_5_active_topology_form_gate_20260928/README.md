# CFL–UEP G3.5 — Active Topology Disambiguation / Non-Probabilistic Form Gate

This branch implements the correction that **Form is never probabilistic**.

Probabilities, Bayesian weights, entropy and scores may be used to choose which observation to acquire next. They never certify state 1. State 1 is emitted only when an exact, claim-specific structural fiber collapses to one equivalence class. A posterior of 0.999999... with multiple exact compatible structures remains pseudo/protoformal, not Form.

G3.5 makes the explanatory fiber the object of O3. A third observation is selected to discriminate mappings, chart families and operators. The benchmark contains:
- prediction-safe/model-ambiguous cases;
- prediction-and-model ambiguous cases;
- already identified controls;
- jurisdictionally non-identifiable cases;
- exact incompatibility (-1) controls;
- a composition lane whose true charts are synthesized from primitive programs rather than named families.

The legacy posterior-threshold rule is retained only as an invalid negative control to measure false Form promotion.

Authority NONE; promotion/canonization blocked.
