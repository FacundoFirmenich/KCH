# CFL–UEP G3.9 — Open Grammar and Meta-Hypothesis Genesis

G3.8 removed the complete model fiber but still supplied a finite authorized grammar that could ultimately be searched for an exact counterexample certificate. G3.9 removes that assumption.

The live epistemic state now includes not only hypotheses but the language that can express them. Residual evidence may trigger new compositions or new derived primitives. Only externally verified productions can enter the reusable append-only library. Later tasks may benefit prospectively; earlier/private tasks can never be retroactively changed.

The most important negative lane is meta-grammar misspecification: if the truth cannot be expressed even after authorized grammar growth, the correct output is MODEL_MISMATCH/ABSTAIN, not forced synthesis.

This branch is design-only. No G3.9 private reserve has been generated or consumed.
