# CFL–UEP G3.5 — Active Topology Disambiguation

G3.4 showed that a future can be uniquely determined while multiple chart/operator explanations remain observationally equivalent. G3.5 therefore changes O3 from a predictor into an **experiment designer**.

For each task, O1/O2 define an exact compatible model fiber. A candidate O3 chooses one new intervention/input from a fixed 24-query pool before its response is revealed. The response then filters the model fiber.

Three regimes are tested: A (prediction unique, model ambiguous), B (both prediction and model ambiguous), and C (model already unique; the correct action is abstention).

The main lane uses the named G3.4 metagrammar. A stress lane places the truth outside that named catalogue but inside a bounded depth-2 chart-composition grammar.

The matched strong baseline is exact claim-aware expected information gain. Authority NONE; promotion/canonization/merge blocked.
