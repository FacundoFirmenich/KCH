# Multistep provenance planning and limits of greedy acquisition

The gate separates computational convenience from mathematical certification. A greedy policy may be useful, but adaptive-submodularity guarantees apply only when the property holds. Our binary certification objective fails that property on an exact finite counterexample.

A separate routing instance demonstrates option value: a low-cost probe that does not immediately change the robust certificate can reduce expected downstream acquisition cost by revealing which expensive provenance test is decisive.
