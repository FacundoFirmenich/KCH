# SCA/CFL Epistemic Rehabilitation v1.2.0

Gate: EPISTEMIC_REHABILITATION_003.

Pregunta: ¿cómo puede una pieza en cuarentena volver a ser operativa sin borrar la historia de por qué fue retirada?

Reglas:
- integridad y autoridad no se rehabilitan mediante evidencia favorable;
- evidencia se cuenta por raíz genealógica, no por número de copias;
- evidencia epistémica suficiente sólo habilita SHADOW;
- la activación requiere evidencia prospectiva adicional + evento explícito de autoridad;
- el registro original de cuarentena permanece inmutable.
