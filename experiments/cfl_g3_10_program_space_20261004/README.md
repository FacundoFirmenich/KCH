# CFL–UEP G3.10 — Generative Program-Space and Meta-Grammar Genesis

G3.9 demonstrated production birth and meta-grammar re-entry, but its expanded program space was still materialized as a bounded candidate list. G3.10 removes that privilege.

Deployable methods receive only typed primitive semantics and AST construction/rewrite operations. Complete candidate programs are generated online. Truth programs in birth lanes are absent from the initial grammar and never handed to deployable methods as precomputed candidates.

The key prospective test is library formation: externally verified recurring subtrees may be promoted to an append-only macro library and must reduce search cost on later tasks only. Private discoveries cannot retroactively alter earlier tasks.

An exhaustive AST search remains only as an oracle ceiling and is excluded from support evidence. No G3.10 reserve has been generated or consumed.
