# External references consulted

- IETF RFC 9943 (2026), *An Architecture for Trustworthy and Transparent Digital Supply Chains*.
- RFC 9162, Certificate Transparency v2.
- Sigsum documentation on witness cosigning and client-side trust policies.
- transparency-dev/Tessera, contemporary transparency-log implementation with witness support.

These are precedents and comparison points. The release does not claim novelty for Merkle logs, threshold witnessing, transparency receipts or append-only checkpointing.
