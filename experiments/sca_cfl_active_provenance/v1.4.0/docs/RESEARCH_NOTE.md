# Active provenance probing under decision-aligned value of information

A finite counterexample separates uncertainty sampling from downstream decision value. A decoy pair has maximal binary entropy but zero ability to change the robust rehabilitation gate. A lower-entropy critical pair can change the decision.

Across 1000 shared hidden worlds, decision-VOI uses 1.0 probe on average, maximum pair-entropy 2.0, and random 1.593; all three have terminal eligibility rate 0.80. This is a finite constructed sample-efficiency result, not a universal performance claim.
