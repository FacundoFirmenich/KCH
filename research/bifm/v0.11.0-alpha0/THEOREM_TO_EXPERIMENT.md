# Theorem-to-experiment bridge

## Formal objects

For admissible systems `M`, a baseline `m0`, an intervened system `me`, and an observation operator `O`, define

`Invisible(O,m0,me) := O(me) = O(m0)`.

A finer observation `O_f` refines a coarser observation `O_c` when there is a deterministic map `r` such that

`O_c = r o O_f`.

## Lean-checked results

1. If `O_f` refines `O_c`, invisibility under `O_f` implies invisibility under `O_c`.
2. If a target property is identifiable from `O_c`, it remains identifiable after adding a probe and observing `(O_c,P)`.
3. Adding a probe therefore cannot destroy structural identifiability already present under the coarser observation.

## Empirical realization

The real-data experiment instantiates:

- systems: baseline and MLP-scaled Qwen inference configurations;
- observations: cumulative signatures from top-1 through vocabulary top-k;
- probes: additional signature components and additional real ARC items;
- target property: the declared intervention state or realized-effect class.

Every exact empirical equality or inequality is evaluated on frozen arrays. No posterior probability is used to override a formal equality test.

## Bayesian role

Across six disjoint real-data blocks, the Bayesian layer estimates variability of the exact collision event within each declared jurisdiction. It answers:

`How frequently does this exact finite-observation collision recur across blocks generated by the frozen design?`

It does not answer:

- whether the target is structurally identifiable for all possible observations;
- whether all prompts or domains are exchangeable;
- whether the system is biologically or phenomenally equivalent to another system.

## Consequence for biologization claims

If a coarse behavioral operator fails to identify even a known internal intervention state, the same evidence cannot by itself identify a stronger biological or phenomenal property. Such an ascent requires a separate bridge whose assumptions and falsifiers must be declared.
