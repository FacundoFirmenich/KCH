## Promotion rule

The main evaluation paper becomes technically submission-ready after:

1. v0.11 exact and Bayesian multisample closure;
2. one third-family or second-domain replication;
3. systematic novelty review;
4. frozen manuscript, code and data release;
5. clean reproduction from the release archive.

External human annotation is not a prerequisite for the formal benchmark. Open-world prose claims remain abstention/transfer cases unless a machine-checkable semantic binding is supplied.
